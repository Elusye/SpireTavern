# QQBot

面向 QQ 群聊的机器人补丁项目。

运行依赖 dsh 0.2.0-rc.2、@tencent-connect/dsh-qqbot 0.5.5 和 Node.js 22。

源码位于 server/qqbot_patch，包括职业卡池、六回合自动对战、按需查看战报、群聊人设、读空气门控和管理员校验。

本仓库不包含密钥、玩家存档、漂流瓶、日志、游戏原始源码或媒体素材。聊天词库 cards.txt、relics.txt 需自行提供。补丁脚本依赖指定版本的安装布局，会重启 dsh-qqbot 服务，使用前检查路径并备份。

这是现有部署的源码快照。按钮能力取决于 QQ 开放平台权限，不可用时可通过 /战报 查看详情。战报缓存在内存，重启后清空。
