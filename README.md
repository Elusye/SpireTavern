# QQBot

面向QQ群聊的官方机器人源码快照，更新至2026-11-23已上线版本。运行基于dsh、@tencent-connect/dsh-qqbot和Node.js 22，原版对战桥接使用Python及独立Linux游戏进程，图片生成使用Pillow和中文字体。

## 当前功能

- 五职业各79张非初始牌；保存各职业牌组，每职业每天抽卡、升级各一次。
- `/对战 @群友`调用0.111.1原版模型适配的双人轮流对战，自动从左向右重扫出牌，首轮保护，直到一方死亡，直接发送图片战报。
- `/抽卡`发送带编号的三选一卡图；`/牌组`每行5张、每页25张，`/牌组 2`翻页；升级牌、重复牌分别展示，编号与删卡/升级一致。图片失败回退文字。
- 群聊猫娘人设、读空气门控、管理员校验、日志分析，以及已有报时/迎新相关补丁。

## 目录与依赖

`server/qqbot_patch/`是机器人模块、图片生成器及针对现有部署布局的补丁脚本。`local-game-validation/enemy-test/`是自编写的游戏适配模组及验证工具，构建需要自行提供合法取得的0.111.1 Linux游戏程序集、GodotSharp与Harmony，使用`dotnet build ... -p:GameData=你的程序集目录`指定位置。

本仓库不包含QQ/模型凭据、SSH密钥、玩家存档、聊天记录、原版游戏文件、反编译源码、构建产物或卡图素材。cards.txt、relics.txt、运行配置和Wiki卡图缓存需在运行环境另行准备。卡图下载器与828张图片文件名清单已包含；图片使用须遵守原作者及来源站要求。

## 部署与验证

这是现有服务器布局的源码备份，并非免配置安装包。先阅读`server/qqbot_patch/NATIVE-ENGINE-OPERATIONS.md`与`CARD-OFFER-IMAGES.md`，核对服务名、路径、依赖和权限。部署脚本会重启服务，应先备份并避免中断对战；不要启动历史NapCat/AstrBot部署。

抽卡/牌组图片须配套安装toys.js、card_offer_image.js、render_card_offer.py及card_image_manifest.json；对战须配套原版模组、职业目录和桥接服务。GitHub更新不会自动部署服务器。

验证包括Node语法检查、合成存档的抽卡/牌组图片流程、原版模型逐牌与交互检查、完整对战和连续运行。原版模型同一版本已通过934次基础/升级逐牌检查、60项关键交互检查、8场完整对战及图片输出；这些样本不能证明所有组合和长期稳定。详细原始测试记录与图片留在本地/服务器，不上传含运行数据的目录。
